# Магазин

Учебный бэкенд интернет-магазина: заказы, цены с НДС, склад, письма клиенту. Три проекта: `Shop.Domain` (сущности и
правила), `Shop.Application` (сервисы и хранилища в памяти), `Shop.Tests` (xUnit).

Сборка — `dotnet build Shop.slnx`, тесты — `dotnet test --project tests/Shop.Tests/Shop.Tests.csproj`.

## Правила

- Деньги — только `Money` (внутри `decimal`). `double` и `float` для денег не используются нигде.
- Округление денег — только `Money.Round()` (банковское, до копеек). Своих `Math.Round` для сумм нет.
- Цена заказа считается в одном месте — `PricingService`; счёт, письма и всё остальное берут суммы у него.
- Текущее время — только через `IClock`; `DateTime.Now`, `DateTimeOffset.Now` и их UTC-варианты в коде не встречаются.
- Нарушение бизнес-правила — `DomainException` с кодом ошибки заглавными буквами (`OUT_OF_STOCK`).
- Все зависимости собираются в `ShopApp` — через него тесты получают сервисы.
- Новое поведение — с тестами в `Shop.Tests`.
